Short-Memory File Agent

    Supported File Types:
  • PDF (.pdf) — Text-based documents
  • Word (.docx) — Extracts paragraph text
  • Excel / CSV (.xls, .xlsx, .csv) — Reads spreadsheet data
  • PowerPoint (.pptx) — Captures slide text
  • HTML (.html, .htm) — Extracts visible page text
  • Text (.txt, .md, .json, .log) — Plain text files
