Short-Memory File Agent

    Supported File Types:
  • PDF (.pdf) — Text-based documents (not scanned images)
  • Word (.docx) — Extracts all paragraph text
  • Excel / CSV (.xls, .xlsx, .csv) — Reads spreadsheet data
  • PowerPoint (.pptx) — Captures text from slides
  • HTML (.html, .htm) — Extracts visible page text
  • Text (.txt, .md, .json, .log) — Any plain-text files
